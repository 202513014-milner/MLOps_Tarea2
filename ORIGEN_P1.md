# Procedencia del código P1
El proyecto parte de los cuatro módulos originales del ZIP aportado. Sus funciones se conservan; GetBestModel se delega a evaluation con su algoritmo P1 disponible como _GetBestModelP1. Se incorporan helpers temporales y de registro. Los artefactos históricos P1 no se incluyen porque utilizaron diez meses para entrenar y no son fuentes válidas para el split 6/4.
